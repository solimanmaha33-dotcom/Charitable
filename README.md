# نظام الجمعية

واجهة عربية لإدارة الأسر والحالات والتبرعات والكفالات. المرحلة الحالية فيها شكل التطبيق والقائمة وصفحات مؤقتة؛ تسجيل الدخول والخدمات هيتضافوا في الخطوات الجاية.

## التشغيل المحلي

استخدم Node.js 24 وnpm. من مجلد المشروع:

```sh
npm ci
npm run dev
```

افتح العنوان اللي بيظهر في الطرفية. الواجهة من اليمين للشمال، وبتشتغل على شاشة عرضها ٣٦٠ بكسل. مفيش إعداد مفاتيح أو خدمات خارجية مطلوب للمرحلة دي.

## الفحص

```sh
npm run test
npm run test:worker
npm run typecheck
npm run build
npm run test:e2e
```

اختبارات الواجهة بتستخدم Vitest وReact Testing Library. اختبار المتصفح بيستخدم Playwright، وبيشغّل الخادم المحلي تلقائياً. لو Chromium بتاع Playwright مش متثبت، ثبّته في بيئة تسمح بتنزيل المتصفحات:

```sh
npx playwright install chromium
```

لو عندك Chromium محلي بالفعل، ممكن تحدد مساره. ده الأمر اللي اتجرب في بيئة الشغل الحالية:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

أمر `test:worker` جاهز لاختبارات `functions/**/*.test.ts` ببيئة Node. لسه مفيش اختبارات أو خدمات Worker؛ خروجه بنجاح حالياً مش دليل إن تكامل Cloudflare اتفحص.

## تنظيم الشغل

- `src/app/`: تشغيل التطبيق والمسارات.
- `src/shared/`: شكل الصفحة والمكونات المشتركة.
- المزايا اللي هتتضاف مكانها `src/features/`، وربط الخدمات مكانه `src/services/`.
- [تقدم الشغل](docs/progress.md) و[خطة التنفيذ](docs/superpowers/plans/2026-11-05-charitable-case-system.md).

المسارات المحمية حالياً بتطلب تسجيل الدخول. صفحة الدخول مؤقتة، ومفيش حسابات أو صلاحيات حقيقية اتنفذت لسه. بنستخدم بيانات وهمية وفحوص محلية فقط؛ التطبيق لسه مش منشور.
