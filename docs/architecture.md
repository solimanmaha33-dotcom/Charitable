# Assistant and reviewed document text

The assistant uses a Cloudflare Pages Function with the Workers AI `AI` binding and the `@cf/meta/llama-3.1-8b-instruct` model. Provider credentials are not delivered to the browser. Workers AI receives the staff member's question and only the case records, explicitly saved document text, and donation records retrieved with that staff member's Supabase session and relevant read permissions. The implementation currently limits each collection to 50 records, so answers and listed sources may be incomplete. The model is instructed to treat document content as untrusted; generated answers and suggestions require human review.

OCR is performed locally. Staff review the draft and a case writer may explicitly save it for search using a Worker route. Search text has the same RLS read boundary as its case file; authenticated clients cannot write the table directly. Field extraction sends a reviewed draft transiently to Workers AI and accepts only `notes` and `case_categories` suggestions with exact quoted evidence. Applying a suggestion is a separate action that edits the case form; the ordinary case save is still required. The employee selects the family.
