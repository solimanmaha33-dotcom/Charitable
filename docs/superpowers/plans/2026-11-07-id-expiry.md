# ID Scanning and Expiry Alerts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scan a family contact's ID locally, let staff confirm its number and expiry date, and flag expired or soon-to-expire cards.

**Architecture:** Add an optional expiry date to the family profile. A client-side parser consumes existing local OCR text and returns editable suggestions. The family ID scan is uploaded through the existing private family-file route. The permission-aware home page lists expired cards and those due within 90 days.

**Tech Stack:** React, TypeScript, existing Tesseract/PDF.js OCR, Supabase Postgres, Vitest, pgTAP.

**Spec:** `docs/superpowers/specs/2026-11-07-id-expiry-design.md`
