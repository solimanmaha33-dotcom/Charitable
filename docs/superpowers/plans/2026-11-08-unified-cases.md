# خطة تنفيذ: قسم الحالات الموحد

## المهام

- [x] **1. أنواع الحالات وترحيلها**: اختبارات لقائمة الاختيارات وحفظ الأنواع الجديدة؛ ترحيل يفرض الأنواع الجديدة على الصفوف الجديدة/المعدلة ويبقي الوسوم القديمة كما هي في السجلات الموجودة.
- [x] **2. دمج مسارات الأسر والحالات**: اختبار قائمة حالات واحدة وروابط ملفات الأسرة؛ نقل دليل الأسر وملف الأسرة تحت مسار الحالات؛ إزالة قسم الأسر من التنقل وتوجيه الروابط القديمة بأمان.
- [x] **3. نموذج الطباعة**: اختبار وجود زر الطباعة ومحتوى نموذج الحالة؛ إضافة صفحة طباعة فقط وCSS للطباعة ورأس شعار الجمعية.
- [x] **4. تبسيط الاستخدام**: اختبار مكان زر الخروج؛ نقله بجوار تبديل الوضع، وإضافة خطوات عربية قصيرة للموظف في قسم الحالات.
- [x] **5. التحقق والتوثيق**: تشغيل اختبارات الواجهة والخدمات والقاعدة والبناء، وتحديث `docs/progress.md`؛ فحص شاشة الهاتف بمتصفح فعلي. فشل التشغيل المتوازي الأول لاختبارات Workers بسبب ضغط الموارد؛ نجحت عند إعادة التشغيل منفردة. قاعدة الاختبار المحلية كانت تحتاج القيد الجديد، وتم تحديثها دون مسحها.
