# خطة: نموذج موحد لإضافة الأسرة والحالة

## المطلوب

إجراء واحد لإنشاء ملف أسرة وحالة مرتبطة به. يبدأ باسم الأسرة ونوع الحالة، ثم اسم الأب الاختياري واسم الأم، واسم المسؤول عن التربية وصلته، ثم بقية بيانات التواصل والبطاقة والملاحظات والملفات.

## التنفيذ

1. إضافة حقول اسم الأب والأم وصلة المسؤول إلى بيانات ملف الأسرة وترحيل SQL بسيط.
2. بناء نموذج إضافة موحد يحفظ الأسرة ثم الحالة والمرفقات، مع إعادة المحاولة بأمان إذا فشل جزء من الحفظ.
3. إزالة زر إنشاء ملف أسرة المنفصل وربط أزرار الإضافة بهذا النموذج؛ إضافة حالة لأسرة موجودة تظل ممكنة من ملف الأسرة.
4. عرض بيانات الوالدين والمسؤول في ملف الأسرة ونموذج الطباعة، وتحديث إرشادات الاستخدام.
5. تشغيل اختبارات الواجهة والخدمات وقاعدة البيانات والبناء واختبار متصفح.
